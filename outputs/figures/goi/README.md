# GOI Figures — RNA-seq Analysis
This folder contains figures summarizing results for selected **Genes of Interest (GOI)**.

---
### Goi Barjit Dunnett Auto12

![Goi Barjit Dunnett Auto12](GOI_barjit_dunnett_auto12.png)
**Bar plot (with jittered points)** showing average expression levels of selected genes of interest across experimental groups. Bars represent mean values; dots show individual sample variation.

---
### Goi Heatmap Auto12

![Goi Heatmap Auto12](GOI_heatmap_auto12.png)
**Heatmap** displaying expression profiles of genes of interest across all samples. Color intensity represents normalized expression (e.g., logCPM or Z-score). Rows are genes; columns are samples.

---
### Goi Violin Auto12

![Goi Violin Auto12](GOI_violin_auto12.png)
**Violin plot** showing per-sample expression distribution for each gene of interest. Wider sections indicate more samples at that expression level; helps visualize group differences.
